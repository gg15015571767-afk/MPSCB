# 简历 — 项目经历

**智能客服系统（MPSCB）** · 个人项目 · Python / Nanobot / DeepSeek / RAG

- **架构与业务闭环**：基于 Nanobot Agent 框架设计「FAQ 匹配 → 向量 RAG → LLM 语义生成 → 自动转人工」的客服流程；通过自定义 MCP Server 实现工单流转，集成飞书与钉钉长连接网关实现双平台实时接入。
- **数据构建与量化评估**：采集清洗 9.1 万条带有 Ground-Truth（最佳回答）的真实电信问答库；编写自动化评估脚本（`eval_retrieval.py`），实测 Top-1 检索平均相似度达 0.864（其中 >0.7 占比 98.7%），实现检索效果的可量化与可复现。
- **模型调优与闭环迭代**：选用 `bge-small-zh` 中文向量模型，通过语义阈值微调（0.45 → 0.55）有效消除了业务词误匹配问题；开发未命中问题挖掘机制（`suggest_faq`），实现高频新问题的知识库自更新闭环。
- **工程化交付**：项目完成 57 个 pytest 单元测试，规范化依赖版本（对齐 PyPI `nanobot-ai==0.3.0`），并通过 Docker Compose 实现容器化部署。

技术栈：Python · Nanobot · DeepSeek · sentence-transformers(bge-small-zh) · SQLite/SQLAlchemy · Docker · MCP
